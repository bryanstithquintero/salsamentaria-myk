Salsamentaria MYK

Plataforma web para el control de ventas, inventario y productos de la Salsamentaria MYK, ubicada en Neiva, Huila, Colombia. Desarrollada con tecnologías web estándar: HTML5, CSS3 y JavaScript puro.

Funcionalidades implementadas

El sistema cuenta con los siguientes módulos activos:

  • Dashboard — Resumen diario con estadísticas en tiempo real, gráfico de ventas y alertas de bajo stock.
  • Gestión de productos — Catálogo con control de inventario, búsqueda, filtros por categoría y exportación a CSV.
  • Formulario de producto — Creación y edición de productos con cálculo automático de margen de ganancia.
  • Historial de ventas — Registro completo de transacciones con filtros por estado y cliente.
  • Registro de ventas — Modal para registrar ventas rápidas directamente desde el historial.
Próximamente: Módulos de Clientes, Proveedores, Realizar venta y Reportes están planificados para la siguiente versión.

Guía rápida de uso

Sigue estos pasos para comenzar a gestionar el negocio:

  1. Ingresa a la página principal e inicia sesión con las credenciales de administrador.
  2. Revisa el Dashboard para ver el resumen del día: ventas, stock y alertas.
  3. Consulta la sección Bajo stock en el dashboard y verifica qué productos necesitan reposición.
  4. Agrega o actualiza productos desde Productos → + Nuevo producto.
  5. Registra ventas manualmente desde Historial → + Registrar venta.
  6. Usa los filtros del historial para analizar el comportamiento de ventas por período y cliente.
  7. Exporta el inventario en CSV desde la página de Productos para respaldo o análisis externo.

Categorías de productos

La Salsamentaria MYK maneja tres líneas de producto:

  • 🥩 Cárnicos — Chorizos, salchichas, salchichones y longanizas artesanales elaborados con carne de res y cerdo de origen regional. Se empacan al vacío para garantizar frescura.
  • 🧀 Lácteos — Quesos frescos, doble crema, mozzarella, yogures y mantequilla provenientes de hatos del departamento del Huila. Elaborados sin conservantes artificiales.
  • 📦 Otros — Productos complementarios como chicharrón prensado y snacks derivados. Amplía la oferta para clientes mayoristas.
Glosario de términos técnicos
Término Definición Ejemplo
SKU Código único que identifica cada producto en el inventario. Permite rastrear existencias y referencias rápidamente. CHO-001
Stock mínimo Cantidad mínima de unidades permitida antes de generar una alerta de reposición. Evita quiebres de inventario. 5 und
Margen de ganancia Porcentaje de utilidad sobre el precio de compra. Se usa para calcular automáticamente el precio de venta sugerido. 35% → compra $4.200, venta $5.670
Ticket promedio Valor promedio de cada transacción de venta en un período determinado. Indicador clave de rendimiento. $ 33.945 por venta
Bajo stock Estado de un producto cuando sus existencias actuales son iguales o menores al stock mínimo configurado. 3 und (mín. 5)
Presentación Formato o empaque en que se vende el producto al cliente final (paquete, libra, botella, etc.). Paquete x 500 g
